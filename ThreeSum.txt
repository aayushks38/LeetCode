Problem Statement

Given an integer array nums, return all unique triplets [nums[i], nums[j], nums[k]] such that:

i != j
i != k
j != k

and

nums[i] + nums[j] + nums[k] = 0

The solution set must not contain duplicate triplets.

Understanding the Problem

We need to find three numbers whose sum equals zero.

Example
nums = [-1, 0, 1, 2, -1, -4]

Valid triplets:

[-1, -1, 2]
[-1, 0, 1]

Notice that:

-1 + (-1) + 2 = 0
-1 + 0 + 1 = 0

The challenge is not only finding triplets but also avoiding duplicates.

Brute Force Approach
Idea

Check every possible combination of three elements.

Use three nested loops:

First loop selects the first element.
Second loop selects the second element.
Third loop selects the third element.

For every triplet:

Calculate the sum.
If the sum equals 0, store it.
Ensure duplicates are not added.
Brute Force Algorithm
Generate all possible triplets.
Check if their sum is zero.
Sort each triplet before storing.
Use a Set to avoid duplicates.
Convert the Set into the final answer.
Brute Force Code
Set<List<Integer>> set = new HashSet<>();

for (int i = 0; i < n - 2; i++) {
    for (int j = i + 1; j < n - 1; j++) {
        for (int k = j + 1; k < n; k++) {

            if (nums[i] + nums[j] + nums[k] == 0) {

                List<Integer> triplet =
                    Arrays.asList(nums[i], nums[j], nums[k]);

                Collections.sort(triplet);

                set.add(triplet);
            }
        }
    }
}
Complexity Analysis
Time Complexity

Three nested loops:

O(n³)
Space Complexity
O(m)

where m is the number of unique triplets stored.

Why Brute Force Is Inefficient

Suppose:

n = 1000

Operations become:

1000³ = 1,000,000,000

This is too slow for interview and competitive programming constraints.

Optimized Approach (Sorting + Two Pointers)
Core Observation

Instead of fixing all three numbers:

Fix only one number.
Find the remaining two numbers using the two-pointer technique.

This reduces one loop.
